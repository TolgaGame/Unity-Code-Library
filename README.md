## 🎮 What is Unity Code Library?

**Unity Code Library** is a growing collection of reusable C# scripts, Unity systems, editor tools, managers, utilities, and ready-to-adapt solutions that can help speed up game development.

The goal is simple:

> **Don't rewrite the same code for every Unity project.**

Instead of spending hours rebuilding common systems, you can browse this repository, find a useful implementation, and adapt it to your own project.

This library is built around practical development experience and focuses on things that are actually useful while building games.

Whether you are prototyping a new idea, working on a mobile game, building editor tools, or developing a larger production project, you may find something here that saves you time.

---

## 🚀 Why This Library?

Unity development often involves writing the same types of systems again and again:

* Ads integration
* Firebase systems
* In-App Purchases
* Localization
* Notifications
* Upgrade systems
* Tutorials
* Internet connection checks
* UI helpers
* Editor utilities
* Mobile privacy / ATT handling
* Game managers
* Debugging tools
* Small reusable components

This repository collects these kinds of solutions in one place.

The purpose is not to create another huge framework.

The purpose is to provide **small, practical, reusable pieces of code that you can understand and integrate quickly.**

## 🧩 How to Use

You can clone the repository:

```bash
git clone https://github.com/TolgaGame/Unity-Code-Library.git
```

Then open or copy the required scripts into your Unity project.

You can also browse the repository directly on GitHub and take only the components you need.

### Recommended Workflow

1. Find the system or utility you need.
2. Read the script before integrating it.
3. Copy it into your project.
4. Adjust namespaces, dependencies, and project-specific settings.
5. Test it in your project.
6. Improve or extend it for your own needs.

---

## ⚠️ Important

This repository is intended as a **developer code library**, not a plug-and-play framework.

Some systems may depend on:

* Specific Unity packages
* Third-party SDKs
* Firebase
* Advertisement SDKs
* Unity packages
* Project-specific classes
* Additional configuration

Always check the source code and dependencies before integrating a system into your project.

You may need to modify parts of the code to match your Unity version and project architecture.
